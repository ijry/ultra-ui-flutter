# ultra_ui example

This installable milestone covers the source main routes and `componentsA`.
Later source component groups and templates remain visible but disabled in the
index until their Flutter migrations are complete.

Run the example on an Android or iOS device:

```sh
flutter pub get
flutter run -d <android-or-ios-device>
flutter test
```

Build a debug Android APK with:

```sh
flutter build apk --debug
```
